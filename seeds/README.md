# Curated discovery hints

`crypto_handles.txt` is an optional operator-maintained list of accounts worth
considering as long-lived discovery entry points. It is not loaded as a fixed
roster, does not define quotas, and has no approved/review version lifecycle.

Add seeds through each platform workspace so they are stored in that platform's
native account and KOL tables with status `seed`. From then on, scheduled
discovery refreshes maintain relationship evidence and promotion state.
