# Product UI References

These three mockups are the current visual and information-architecture baseline:

- `trend-radar-multiplatform.png`: cross-platform themes stay separate from each platform's native ranks.
- `kol-discover-platform-specific.png`: users select one platform before discovering and ranking KOL accounts; no cross-platform KOL aggregation.
- `kol-watchlist-multiplatform.png`: a unified newest-content feed preserves platform, content type, publication time, retrieval time, and source health.

The images contain fictional people and mock data. They describe product behavior, not currently enabled production providers.
